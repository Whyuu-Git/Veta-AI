# Frontend — AI Research Companion (Flutter)

## Struktur folder
- lib/screens    -> satu folder per fitur utama (setup, dashboard, research, mentor, intelligence, profile)
- lib/widgets    -> komponen UI yang dipakai berulang
- lib/models     -> representasi data dari API backend
- lib/services   -> komunikasi ke backend (HTTP)
- lib/providers  -> state management (Provider/Riverpod)
- lib/utils      -> fungsi bantu (validasi, dll)
- lib/constants  -> warna, route, konstanta lain
